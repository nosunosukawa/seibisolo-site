ふりがな整備士のアプリは、個人のデータを集めません。アカウント・解析・広告はありません。学習記録は、あなたの端末と、あなたの iCloud にだけ保存されます。

アプリ

集める情報

ありません。解析ツール、クラッシュレポート、広告識別子、データを集める第三者 SDK は使っていません。アプリは開発者のサーバーと通信しません。問題・解説・訳・図はすべてアプリの中に入っています。

データの保存場所

解いた記録・苦手の印・設定は、端末の中のアプリに保存されます。アプリを削除すると消えます。

設定で「iCloud で記録を引き継ぐ」を入れると、同じ記録をあなたの iCloud（Apple の iCloud キーバリューストレージ）に保存し、同じ Apple ID の端末どうしでそろえます。保存先はあなたの iCloud で、開発者はその中身を見られません。切ると、それ以降は iCloud に書きません。

「記録を書き出す」で作るファイルの送り先は、あなたが共有シートで選びます。開発者が受け取ることはありません。

購入

級ごとの購入は App Store を通じて Apple が処理します。アプリは、この Apple ID がどの級を購入済みかを Apple に尋ねるだけです。お支払いの情報はアプリや開発者から見えません。

このウェブサイト

  • サイトは GitHub Pages で公開しています。ページを開くと、接続の記録（IP アドレスなど）を GitHub が扱うことがあります。
  • このサイトは、外部のフォントや解析ツールを読み込みません。ふりがなと文字の大きさの設定は、あなたのブラウザの中に保存します。
  • 「テスト版の入れ方」のページ（try.html）だけ、X（旧 Twitter）の広告の効果を測るために X Pixel を使っています。このページを開くと、X がクッキーなどで閲覧を記録することがあります。扱いは X のプライバシーポリシーをご覧ください。
  • App Store へのボタンには、どのページから来たかを数えるための印が付いています。誰が押したかは分かりません。

お問い合わせ

メールでお問い合わせいただくと、メールアドレス、お名前（書かれていれば）、本文を受け取ります。お返事と、不具合や誤りを直すためだけに使います。法令で必要な場合を除いて、ほかの人に渡しません。Google のメール（Gmail）を使っています。消してほしいときは、同じアドレスへお知らせください。

English

The Furigana Seibishi app does not collect any personal data. There are no accounts, analytics, ads or third-party SDKs that collect data, and the app does not talk to the developer's servers. Study records stay on your device and, if you turn on iCloud sync, in your own iCloud, which the developer cannot see. Purchases are processed by Apple. The website is hosted on GitHub Pages, which may process connection logs. It loads no third-party fonts or analytics, except that the test-install page (try.html) uses the X Pixel to measure X ads. If you email us, we use your message only to reply and to fix problems. Contact: nosunosukawa@gmail.com.
